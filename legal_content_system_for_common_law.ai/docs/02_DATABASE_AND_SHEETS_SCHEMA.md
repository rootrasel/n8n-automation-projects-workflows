# Database & Google Sheets Schema Reference

The Common-Law.ai pipeline uses a synchronized Google Sheets database (or relational database) containing four core tables:
1. `Topic_Bank`: Candidate and approved legal topics, jurisdiction, and priority scores.
2. `Publishing_Queue`: Article publication queue, WordPress post IDs, scheduled times, and syndication status.
3. `Directory_Lookup`: Attorney directory URL routing, state codes, and dynamic CTA copy.
4. `Execution_Logs`: System-wide audit trail, execution logs, and automated error tracking.

---

## 1. `Topic_Bank` Sheet

Stores all researched legal ideas generated by **WF1** & **WF2**, or imported manually by the editorial team.

| Field Name | Type | Example | Description |
| :--- | :--- | :--- | :--- |
| `topic_id` | String (PK) | `TOPIC-1729060000-001` | Unique topic identifier assigned at creation. |
| `title_idea` | String | `What Happens If Someone Dies Without a Will in Texas?` | Working article title formulation. |
| `primary_keyword` | String | `dying without a will texas intestate succession` | Target SEO search query. |
| `target_state` | String | `Texas` | Primary jurisdiction (`Federal` or State name). |
| `practice_area` | String | `Estate Planning` | Taxonomy category (Family Law, Corporate, etc.). |
| `source_type` | String | `wf2_research` | Discovery mechanism (`wf2_research`, `gap_engine`, `manual`). |
| `relevance_score` | Number | `95` | Editorial score (1–100) based on intent and commercial value. |
| `status` | Enum | `NEW` | Lifecycle state: `NEW`, `APPROVED`, `IN_PROGRESS`, `PUBLISHED`, `REJECTED`. |
| `suggested_date` | Date (ISO) | `2026-10-18` | Target date for scheduling. |
| `notes` | Text | `High consumer search demand matching Texas directory.` | AI editorial rationale or editor notes. |
| `created_at` | Timestamp | `2026-10-16T08:00:00Z` | Record creation timestamp. |

## 2. `Publishing_Queue` Sheet

Tracks articles from WordPress draft creation through live publication and social distribution.

| Field Name | Type | Example | Description |
| :--- | :--- | :--- | :--- |
| `queue_id` | String (PK) | `QUEUE-101` | Queue reference ID (`QUEUE-{wp_post_id}`). |
| `topic_id` | String (FK) | `TOPIC-1729060000-001` | Reference to parent record in `Topic_Bank`. |
| `wp_post_id` | Number | `101` | WordPress Post ID returned by WP REST API. |
| `article_title` | String | `Texas Intestate Succession: Dying Without a Will Guide` | Final post title published on site. |
| `slug` | String | `texas-intestate-succession-guide` | SEO permalink slug. |
| `scheduled_publish_time` | Timestamp | `2026-10-17T09:00:00Z` | Target publishing window for WF5. |
| `wp_status` | Enum | `draft` | WordPress post state: `draft`, `future`, `publish`, `trash`. |
| `social_status` | Enum | `PENDING` | Syndication state: `PENDING`, `DISTRIBUTED`, `FAILED`, `BLOCKED`. |
| `article_url` | String | `https://common-law.ai/texas-intestate-succession-guide/` | Public canonical URL. |
| `featured_image_url` | String | `https://common-law.ai/wp-content/uploads/texas-will.png` | Live media asset URL attached to post. |
| `notes` | Text | `Verified HTTP 200` | Operational status or error reason. |

---

## 3. `Directory_Lookup` Sheet

Maps user geography and practice areas to active attorney directory listings for dynamic CTA insertion.

| Field Name | Type | Example | Description |
| :--- | :--- | :--- | :--- |
| `state_code` | String (2) | `TX` | Standard two-letter US Postal state abbreviation. |
| `state_name` | String | `Texas` | Full state name. |
| `practice_area` | String | `Estate Planning` | Legal practice area specialty. |
| `has_active_attorneys` | Boolean | `TRUE` | `TRUE` if directory has verified listings; `FALSE` triggers fallback. |
| `custom_directory_url` | String | `https://common-law.ai/attorneys/?state=texas&practice=estate-planning` | Deep link to filtered attorney directory. |
| `cta_headline` | String | `Find a Verified Texas Estate Planning Attorney` | Personalized CTA headline. |
| `cta_button_text` | String | `Browse Texas Attorneys &rarr;` | Call to action button text. |
| `fallback_url` | String | `https://common-law.ai/get-matched/` | General attorney intake matching form. |

---

## 4. `Execution_Logs` Sheet

Populated automatically by **WF7 (Monitoring & Error Handling)** to track system health and alert history.

| Field Name | Type | Example | Description |
| :--- | :--- | :--- | :--- |
| `execution_id` | String (PK) | `EXEC-1729060000-001` | Unique n8n execution identifier. |
| `workflow_id` | String | `wf02-topic-ranking` | n8n workflow identifier. |
| `workflow_name` | String | `WF2 — Legal Topic Research and Ranking` | Human-readable workflow title. |
| `status` | Enum | `SUCCESS` | `SUCCESS`, `ERROR`, `RETRYING`, `MANUAL_REQUIRED`. |
| `error_message` | Text | `CourtListener API timeout after 15000ms` | Raw error payload from failed node. |
| `error_node` | String | `Research Competitors & Legal Sources` | Exact node where exception occurred. |
| `recorded_at` | Timestamp | `2026-10-16T09:02:15Z` | Event timestamp (ISO 8601). |
| `retry_count` | Number | `2` | Number of automated retries attempted. |
| `notes` | Text | `Max retries exhausted. Alert dispatched to Slack.` | Actionable recovery notes. |
